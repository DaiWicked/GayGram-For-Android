## О проекте

**GayGram — Android-клиент Telegram от 缺德组织.**

Основан на <a href="https://github.com/monogram-android/monogram">Monogram</a> — нативном клиенте на Kotlin и Compose с протоколом на Rust. Поверх этой основы мы добавили две вещи: слой стекла на контролах и слой тактильной отдачи.

Это не «официальный клиент с набором тумблеров». Интерфейс переделан под телефон, а функции переносятся по одной из нашего же десктопного клиента под Windows.

## Возможности

| Категория | Что внутри |
| --- | --- |
| 🫧 Стекло и отдача | Жидкое стекло на верхних панелях, поле ввода, кнопке перехода и за меню; отклик на касания, долгие нажатия, переключатели и упор списка в край |
| 👻 Приватность | Защита от отзыва сообщений, режим призрака (скрыть онлайн / прочтение / набор), история сообщений |
| ✨ Улучшения | Локальный Premium, автоперевод, фильтры сообщений |
| 🧱 Основа | Нативный Kotlin + Compose, Rust MTProto, папки, вход по QR / passkey |

Ещё переносится с десктопа: настройка внешнего вида, свои шрифты, аврора-градиент, размытие обоев, биометрическая блокировка, динамическая иконка, виджеты на домашнем экране.

## Чем отличается

### Стекло

Верхние панели, поле ввода, кнопка перехода к последним сообщениям, область за меню — эти контролы под стеклом. Сообщения, которые скроллятся под ними, размываются, а на скруглениях видна небольшая рефракция.

На самих сообщениях стекла нет. Когда читаешь — хочешь читать, а не смотреть сквозь матовое стекло.

### Тактильная отдача

Касание, долгое нажатие, переключатель, список, дотащенный до конца — у каждого свой отклик. Если список уже внизу, а ты тянешь дальше, раздаётся один щелчок, как будто упёрся в стену. Если отпустил и он докатился по инерции — молчок, потому что это тянул не ты.

Не нравится — выключи в «Настройки → Оформление» или пусть следует системе.

## Скачать

Свежий APK — в [Releases](https://github.com/DaiWicked/GayGram-For-Android/releases). Разреши установку из неизвестных источников и ставь. Для первого входа нужен свой аккаунт Telegram; если нужны уведомления — дай приложению разрешение в системных настройках.

Работает на Android 7.0 и новее.

> Личный проект: не официальное приложение Telegram и не публикуется ни в одном магазине. Что-то не так — открой issue.

## Сборка из исходников

Мы собираем через GitHub Actions. Для локальной сборки понадобятся:

- JDK 17+
- Android SDK (Platform 37)
- Rust + NDK (mtproto на Rust, через UniFFI)
- свои `API_ID` / `API_HASH` от Telegram
- выложенный **рядом** с репозиторием `telers-mtproto-impl` (манифесты Cargo читают `../telers-mtproto-impl`; submodule в `vendor` этого не заменяет)

Подробности — в `AGENTS.md` в корне репозитория; писалось для AI-сотрудников, но людям тоже понятно.
