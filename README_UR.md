<p align="center"><strong>GayGram</strong> ایک ٹیلی گرام کلائنٹ ہے جو میں نے اپنے لیے بنایا۔</p>

یہ <a href="https://github.com/monogram-android/monogram">Monogram</a> پر پلا بڑھا — Kotlin اور Compose میں لکھا ہوا مقامی کلائنٹ، پروٹوکول کی تہہ Rust میں۔ اِس بنیاد پر میں نے دو چیزیں شامل کیں: ایسا شیشہ جو واقعی اپنے پیچھے کی چیز کو توڑتا ہے، اور ایسی ہیپٹک تہہ جو بات کرتی ہے۔

## شیشہ

اوپری بار، پیغام لکھنے کا خانہ، تازہ ترین پیغامات تک جانے کا بٹن، مینو کے پیچھے کی ونڈو — یہ شیشہ ہیں، اور اِن کے پیچھے جو ہے وہ واقعی مڑتا اور بہتا ہے۔

پیغامات پر خود شیشہ نہیں آتا۔ پیغام پڑھتے وقت آدمی صرف پیغام دیکھنا چاہتا ہے۔

## ہیپٹک

ٹیپ، دیر تک دبانا، سوئچ، تصدیق، انکار، فہرست کو آخر تک گھسیٹنا — ہر ایک کا اپنا احساس ہے، اِس لیے بغیر دیکھے پتہ چل جاتا ہے کہ کیا ہوا۔

جب فہرست پہلے ہی تہہ میں رُکی ہو اور آپ اُسے مزید کھینچیں تو ایک بار «ٹک» ہوتا ہے، جیسے دیوار کو چھو لیا ہو۔ اُسے اُچھال کر رفتار کے ساتھ وہاں پہنچنے پر وہ خاموش رہتی ہے، کیونکہ وہ کھینچ آپ کا نہیں تھا۔

نہیں چاہیے؟ «ترتیبات → ظاہری شکل» میں بند کر دیں، یا سسٹم کی پیروی کرنے دیں۔

## راستے میں

اِسی نسب کا Windows ڈیسک ٹاپ کلائنٹ ایک ایک کر کے یہاں آ رہا ہے — اسکرین نقلاً نہیں لائے جاتے۔ ہر ایک موبائل کے لیے نئے سرے سے بنایا جاتا ہے:

پیغام کے حذف ہونے سے حفاظت، گھوسٹ موڈ، پیغامات کی تاریخ، مقامی پریمیم، مترجم، فلٹرز۔

## ایک بار چلا کر دیکھیں

[Releases](https://github.com/DaiWicked/GayGram-For-Android/releases) سے تازہ ترین APK ڈاؤن لوڈ کریں، نامعلوم ذرائع سے ایپس کی تنصیب کی اجازت دیں اور نصب کر لیں۔ پہلی بار لاگ اِن کرنے کے لیے اپنا ٹیلی گرام اکاؤنٹ درکار ہوگا؛ اطلاعات چاہیں تو سسٹم ترتیبات میں اجازت دے دیں۔

Android 7.0 اور اُس سے نئے پر چلتا ہے۔

> [!NOTE]
> یہ ذاتی منصوبہ ہے: ٹیلی گرام کی سرکاری ایپ نہیں اور کسی اسٹور پر شائع نہیں ہوتا۔ کچھ عجیب محسوس ہو تو issue کھول کر بتائیں۔
