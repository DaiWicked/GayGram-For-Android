## تعارف

**GayGram 缺德组织 کی طرف سے بنایا گیا Android ٹیلی گرام کلائنٹ ہے۔**

یہ <a href="https://github.com/monogram-android/monogram">Monogram</a> پر مبنی ہے — Kotlin اور Compose میں لکھا ہوا مقامی کلائنٹ، پروٹوکول کی تہہ Rust میں۔ اِس بنیاد پر ہم نے دو چیزیں رکھیں: کنٹرولز پر ایک شیشے کی تہہ، اور ہیپٹک فیڈبیک۔

یہ "آفیشل کلائنٹ جس پر ڈھیر سارے ٹوگلز لگے ہوں" والی بات نہیں۔ UI کو موبائل کے لیے نئے سرے سے بنایا گیا ہے، اور فیچرز اسی گروپ کے Windows ڈیسک ٹاپ کلائنٹ سے ایک ایک کر کے منتقل کیے جا رہے ہیں۔

## فیچرز

| زمرہ | کیا ہے |
| --- | --- |
| 🫧 شیشہ اور ہیپٹک | اوپری بارز، ان پٹ بار، تازہ ترین میسج پر جانے والا بٹن، مینوز کے پیچھے مائع شیشہ؛ ٹیپ، دیر تک دبانے، سوئچ اور لسٹ کے کنارے پہنچنے پر اپنا اپنا محسوس |
| 👻 رازداری | میسج ڈیلیٹ ہونے سے بچاؤ، گھوسٹ موڈ (آن لائن/پڑھا/لکھ رہا ہے چھپائیں)، میسج ہسٹری |
| ✨ ایکسٹرا | مقامی پریمیم، خودکار ترجمہ، میسج فلٹرز |
| 🧱 بنیاد | مقامی Kotlin + Compose، Rust MTProto، فولڈرز، QR / passkey سے لاگ ان |

ڈیسک ٹاپ سے ابھی منتقل ہو رہے ہیں: ظاہری ترتیبات، اپنی فونٹس، ارورہ گریڈینٹ، وال پیپر بلاکر، بایومیٹرک لاک، ڈائنامک آئیکن، ہوم اسکرین ویجیٹس۔

## کیا چیز اسے الگ بناتی ہے

### شیشہ

اوپری بار، ان پٹ فیلڈ، تازہ ترین میسج والا بٹن، مینوز کے پیچھے کا علاقہ — یہ کنٹرولز شیشے کے نیچے ہیں۔ پیچھے سے سکرول ہوتے میسج دھندلے نظر آتے ہیں، اور گول کناروں پر ہلکا سا انعطاف نظر آتا ہے۔

میسجز پر خود شیشہ نہیں۔ جب پڑھ رہے ہوں تو پڑھنا چاہتے ہیں، دھندلے شیشے کے پار سے نہیں۔

### ہیپٹک

ٹیپ، دیر تک دبانا، سوئچ، لسٹ کو آخر تک گھسیٹنا — ہر ایک کا اپنا احساس ہے۔ جب لسٹ پہلے ہی تہہ میں ہو اور آپ مزید کھینچیں تو ایک بار «ٹک» ہوتا ہے، جیسے دیوار سے ٹکرا گئے۔ اُسے اُچھال کر رفتار سے پہنچے تو خاموش رہتی ہے، کیونکہ وہ کھینچ آپ کا نہیں تھا۔

نہیں چاہیے؟ ترتیبات → ظاہری شکل میں بند کر دیں، یا سسٹم کی پیروی کرنے دیں۔

## ڈاؤن لوڈ

تازہ ترین APK [Releases](https://github.com/DaiWicked/GayGram-For-Android/releases) سے لیں، نامعلوم ذرائع سے انسٹال کرنے کی اجازت دیں اور لگا لیں۔ پہلی بار لاگ اِن کے لیے اپنا ٹیلی گرام اکاؤنٹ درکار ہوگا؛ اطلاعات چاہیں تو سسٹم ترتیبات میں اجازت دے دیں۔

Android 7.0 اور اُس سے نئے پر چلتا ہے۔

> یہ ذاتی منصوبہ ہے: ٹیلی گرام کی سرکاری ایپ نہیں اور کسی اسٹور پر شائع نہیں ہوتا۔ کچھ عجیب لگے تو issue کھول دیں۔

## سورس سے بنانا

ہم اپنا ریلیز GitHub Actions سے کرتے ہیں۔ مقامی طور پر بنانے کے لیے چاہیے:

- JDK 17+
- Android SDK (Platform 37)
- Rust + NDK (mtproto Rust میں ہے، UniFFI کے ذریعے)
- اپنی ٹیلی گرام `API_ID` / `API_HASH`
- ریپو کے **ساتھ** `telers-mtproto-impl` کی کلون (Cargo manifest `../telers-mtproto-impl` پڑھتے ہیں؛ `vendor` کے نیچے submodule کافی نہیں)

تفصیلات ریپو کے روٹ میں `AGENTS.md` میں ہیں — AI مددگاروں کے لیے لکھی گئی، انسان بھی پڑھ سکتا ہے۔
